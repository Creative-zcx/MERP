01 / OVERVIEW

Three perspectives.
One emotional context.

Human emotion is rarely carried by a single cue. MERP learns from what is said, how it sounds, and what can be seen—while remaining testable when one modality is missing.

01

Language

Semantic features preserve what the speaker says and provide the sequence around each emotional cue.

300-d input
02

Vision

Visual descriptors carry facial and behavioral signals that complement the spoken message.

35-d input
03

Acoustics

Prosodic features capture tone, intensity, and rhythm—the emotional texture behind the words.

74-d input

02 / ARCHITECTURE

A shared space for
cross-modal reasoning.

Perceiver IO decouples input size from model depth. Modality-specific streams enter a compact latent bottleneck, then label-aware queries decode a representation for each emotion.

Unified representation

A shared latent array lets heterogeneous streams interact without requiring identical feature dimensions.

02

Label-aware decoding

Trainable output queries and label attention produce class-specific representations for multi-label prediction.

03

Missing-modality evaluation

Deterministic modality masking enables controlled robustness experiments on aligned and unaligned data.

04

Representation learning

Prototype memory, contrastive objectives, reconstruction, and gated score fusion shape the latent space.
